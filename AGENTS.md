## 🛠️ Tech Stack & Standards

- **React 19 & TypeScript**:
  - Always write clean, modern, and idiomatic React 19 functional components.
  - Maintain strict TypeScript type safety. Avoid using `any`; define explicit interfaces/types for props, states, and API responses.
- **Styling**:
  - Use **Tailwind CSS** for styling.
  - Adhere to the design system (Deep Navy and Orange palette) defined in `tailwind.config.js`. Avoid arbitrary styling or hardcoded color codes (like standard `#000` or `#fff`) where possible.

  - Use **React Router v7** (`react-router-dom`) for all page routing. Ensure dynamic route parameters are typed and handled correctly.

## 🔒 Security & Best Practices

- **Environment Secrets**:
  - Never commit `.env`, `.env.local`, or any credentials/API keys to the Git repository.
  - Access Gemini API, Firebase SDK configs, and other secrets using environment variables or Cloudflare bindings.
- **Pre-deployment Verification**:
  - Before declaring a UI task or backend feature complete, run `npm run build` locally to verify that TypeScript compiles without any errors and that Vite successfully bundles the app.
  - **Preventing White Page Errors (Blank Screen)**:
    - Ensure all routes are served with SPA fallback routing (e.g., verifying `index.html` copy to `200.html` exists in the build output scripts) to prevent 404 / blank screens on direct link visits.
    - Never assume environment variables exist; always use safe fallbacks (e.g., `import.meta.env.VITE_VAR || 'default'`) to prevent JS reference errors on initialization.
    - Check the console for any unhandled exceptions during local runtime verification before pushing.
    - **Troubleshooting Blank Page on Custom Domain**:
      - **Symptom**: Custom domain showed a blank page while pages.dev worked.
      - **Console error**: Failed to load module script... MIME type "text/html"
      - **Root cause**: A JavaScript chunk request returned HTML instead of JavaScript due to Cloudflare caching/routing.
      - **Resolution**: Purge the entire Cloudflare cache (not just individual files) so JS assets are served with the correct content type.
        - **Steps to Purge Entire Cloudflare Cache**:
          1. Log in to the Cloudflare Dashboard and select the domain (`shikshasahayak.org`).
          2. Navigate to **Caching** → **Configuration** in the left sidebar.
          3. Under **Purge Cache**, click the **Purge Everything** button and confirm.
          4. Alternatively, execute `npm run deploy` with `CLOUDFLARE_ZONE_ID` and `CLOUDFLARE_API_TOKEN` defined in your environment to run automated cache purging (`scripts/purge-cache.js`).
