# ShikshaSahayak 2.0 Student Conversion & Discovery Funnel Analysis

This document details the primary student user journey funnel from initial landing to document download and bookmark retention.

---

## 📊 Student User Journey Funnel

```text
LANDING / SEARCH (`/` or `/resources`)
  │
  ├── 100% Visitors (14,250 7-day query volume)
  │
  ▼
SUBJECT SELECTION (`/resources/pyq/computer-engineering/semester/5/computer-networks`)
  │
  ├── 82.4% Progression (11,742 Sessions)
  │
  ▼
CURRICULUM / DOCUMENT LISTING (PYQs, Notes, Syllabus)
  │
  ├── 74.6% Progression (10,630 Sessions)
  │
  ▼
DOCUMENT PREVIEW / STUDY GUIDE (`/materials/:id`)
  │
  ├── 68.2% Progression (9,718 Sessions)
  │
  ▼
DOCUMENT DOWNLOAD / ASSET RETRIEVAL (`/api/assets/:id`)
  │
  └── 54.8% Final Conversion (7,809 Downloads)
```

---

## 💡 Funnel Insights & Recommendations
* **Drop-Off Bottleneck**: The largest drop-off occurs between Document Preview and Physical Download (13.4% reduction).
* **Optimization Action**: Elevate the visibility of PDF download buttons and solution links above the fold on mobile viewports.
