A simple map of the one database behind ShikshaSahayak — designed so a non-technical person can understand what each table stores and how the pieces connect.

🧭 The 30-second understanding

Users are people. Academic tables describe universities, courses, colleges, branches and subjects. Documents hold learning content. Classes, quizzes and assignments hold learning activities.

University→Course→Branch→Subject
User→Student Profile→Classes / Quizzes / Assignments
Tip: Use the search box above, or collapse sections you don't need. Every table can also be opened/closed individually.

🔑 How to read a table

🔑 PK = the record's unique ID.

🔗 FK = a connection to another table.

🔒 UNIQUE = two rows cannot use the same value.

✅ 0 / 1 = No / Yes.

🕒 timestamp = when something happened.

Key decisions: Branch slug is removed. Branch ID example is gtu_be_016. Semester stays a normal number — there is no semester table.

🔗 Most important connections

universities→courses

A university offers many courses.

universities→colleges

A university has many colleges.

universities→branches

Branches belong to a university.

courses→branches

A course contains many branches.

branches→subjects

A branch has subjects.

subjects→documents

Subjects have learning documents.

documents→document_files

Documents can have files.

file_assets→document_files

Stored files are linked to documents.

users→student_profiles

A user can have one student profile.

users→teacher_profiles

A user can have one teacher profile.

classes→class_enrollments

Students join classes.

classes→assignments

Classes receive assignments.

assignments→assignment_submissions

Students submit assignments.

quizzes→questions

Quizzes contain questions.

quizzes→quiz_attempts

Students make quiz attempts.

attendance_sessions→attendance_records

Sessions produce attendance records.

message_threads→messages

Threads contain messages.
